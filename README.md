# 🎓 Risk Training Academy (RTH)

An interactive compliance and risk training platform for Risk & Compliance Operations teams.

## Features
- 📚 **Knowledge Base** — Searchable procedure docs, glossary, and reference materials
- ⚖️ **Decision Matrix** — Interactive decision trees for every case type
- 🎯 **Training Simulator** — 40 scenarios across 3 difficulty levels
- 🌍 **Geography Training** — 135 questions on scripts, countries, and sanctioned territories
