## How to Use This Knowledge Base

This knowledge base is organized into two sections:

- **Core Reference** — Shared procedures, templates, and definitions used across all clients. When you see a cross-reference like `→ See Core Procedures`, that means the step is identical for every client and lives here to avoid repetition.
- **Client Procedures** — Full, self-contained, step-by-step guides for each client. You can work an entire case from a single client doc.

> **For compliance investigators:** Your client procedure doc is your primary reference. Use Core Reference docs when you need deeper detail on a shared topic.
