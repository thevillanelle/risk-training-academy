User Guide & FAQs

Everything you need to know to get the most out of RTH — from searching the Knowledge Base to running training scenarios and understanding your location theme.

⚖️
What is RTH?
Overview of the platform

The Risk Training Academy (RTH) is an internal learning and reference tool for Risk & Compliance Operations investigators. It consolidates procedure documentation, interactive decision tools, and training simulations — accessible on company VPN from any device.

📚 Knowledge Base

Searchable procedure docs, full glossary/dictionary, and reference materials. In progress — full database coming soon.

⚖️ Decision Matrix

Interactive decision trees for every case type. Answer questions, get the correct action and reason code instantly.

🎯 Training Simulator

Work real compliance scenarios across 3 difficulty levels. 40 scenarios covering all clients, events, and edge cases.

🌍 Where in the World?

Geography and language identification training — scripts, country names, name origins, and sanctioned territories. 135 questions across 4 modes.

📚
Knowledge Base
How to search, browse, and use the KB
1
Search for anything
Type any term, procedure name, reason code, or keyword into the search bar. Results update live. Try: batch_type_a_registrant, sanctioned countries, 2/3 name match, Cleared by DOB.
2
Use the sidebar to filter
Dictionary — term definitions only. Originals — condensed source doc summaries. Tech Edits — clean rewrites of the same docs. Client tabs filter by Program Alpha, Program Beta, Program Gamma, or Pending.
3
Click a card to expand it
The preview text disappears and the full content appears. Click again to collapse.
4
Copy source doc URLs
Every relevant card has a 📋 Copy source URL button. Click it, then paste in a fresh browser tab. Direct navigation is blocked by the compliance site's security headers — this is the workaround.
⚙️ In Progress: The Knowledge Base database is still being built. Always reference the official source docs for audit and escalation decisions.

Decision Matrix
Getting the right action and reason code instantly
1
Select your matrix type
With PII · Program Gamma — No PII · Companies · Batch Free Dev
2
Answer each question
Entity type → name match → DOB → location. The progress bar shows where you are.
3
Read the result
Shows action (CLEAR, ESCALATE, or SUSPEND), the exact reason code, an explanation, and your full decision path.
Tip: When in doubt — escalate. The matrix is a decision support tool, not a replacement for your judgment on individual case details.

Training Simulator
40 scenarios, 3 difficulty levels
1
Choose your difficulty
🌿 Initiate — 13 clear-cut scenarios. ⚡ Investigator — 13 mixed scenarios including China naming, YOB shortcuts, expired PII. 🔱 Olympian — 14 edge cases: full address match exceptions, ownership traps, System Notes sanctions connections.
2
Work each case
Review Screened Entity and Matched Data. Choose the correct action. You have 3 lives (🌿🌿🌿). Streak of 3+ correct earns a bonus.
3
Read the feedback
Every question — right or wrong — shows the full reasoning. Wrong answers are often the most educational.

Frequently Asked Questions
Click any question to expand
Why do the source doc links say "Copy URL" instead of just opening? +
The compliance investigations site sets a Cross-Origin-Opener-Policy security header that blocks pages being opened via direct links from external domains. The workaround: click 📋 Copy source URL, open a fresh browser tab, and paste. This bypasses the restriction entirely.
Are the Knowledge Base articles the official procedure documents? +
No — always use the official source docs for audit and escalation decisions. The KB has Originals (condensed summaries) and Tech Edits (restructured rewrites). Neither is verbatim. Official docs: compliance.vilecorp.com. Full content database is in progress.
Do I need VPN to use RTH? +
Yes. RTH is hosted on GitHub Pages (pages.github.com), only accessible on Apple's internal network. If you see a connection error, check your VPN first.
Why is the Knowledge Base "in progress"? +
We're building a database backend for full procedure docs with real-time updates — so content can be maintained without touching code. The Dictionary, Decision Matrix, Training Simulator, and Geography Training are fully complete now.
How do I send a colleague directly to the Decision Matrix (or any section)? +
Use hash links: …/#kb · …/#matrix · …/#training · …/#guide. Or navigate there yourself and copy the URL from the address bar — it updates live.
What's the difference between "Original" and "Tech Edit" in the KB? +
Originals: condensed summaries of the source docs — same structure, shorter. Include a copy-URL button for the full official version.

Tech Edits: complete rewrites — cleaner structure, less redundancy, decision tables instead of paragraphs. Same coverage, better readability.
Is the Training Simulator based on real compliance cases? +
Scenarios are based directly on patterns in the official procedure documents using anonymized, illustrative names. No actual case data is used.
Does my Training Simulator score save? +
Not currently — scores reset each session. Persistent score tracking and leaderboards are planned for the database phase. Note your accuracy percentage at the end of each session for now.
Can I use RTH on mobile? +
Yes — RTH is responsive and works on iPhone and iPad with VPN. Best experience is on desktop due to content density, but all tools are fully functional on mobile.
What does RTH stand for, and what's the 🎓 symbol? +
RTH = Risk Training Academy. The 🎓 caduceus is a nod to CMS (the Greek messenger god who carries the caduceus) — since CMS (the tool investigators use daily) stands for Case Management System. RTH was renamed to avoid confusion with CMS itself.
How current is the procedure content? +
Built from source documents as of May 2026. Always check compliance.vilecorp.com for the latest — especially after policy changes (e.g., Syria's removal from the sanctions list in November 2025).
I found an error or want to suggest new content — who do I contact? +
Reach out to Krystine Hall via Slack or the compliance investigations team channel. New scenarios, dictionary terms, and bug reports are always welcome.
